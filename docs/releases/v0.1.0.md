# DevDataAPI v0.1.0

**Release date:** 2026-10-25  
**Status:** Early preview

DevDataAPI v0.1.0 is the first downloadable preview. It provides typed REST CRUD operations backed by local JSON files, sample data, and interactive OpenAPI documentation.

## Included

- Executable Spring Boot JAR targeting Java 25.
- CRUD routes for users, products, and orders under `/api`.
- Synthetic JSON datasets for those domains and additional sample categories.
- Aggregated resource reads across matching JSON data files.
- Duplicate-ID warnings and last-occurrence-wins behavior for users, products, and orders.
- OpenAPI specification and Swagger UI.

## Quick start

Install Java 25 or later, download `dev-data-api-0.1.0.jar` from the GitHub Release, and run:

```bash
java -jar dev-data-api-0.1.0.jar
```

The server listens on port `8081` and uses `./data` relative to the current working directory by default. Set `DEVDATAAPI_DATA_DIR` to select another data directory.

Try `http://localhost:8081/api/users` or open `http://localhost:8081/swagger-ui/index.html`.

## Important limitations

This is an early preview for local development. It has no authentication or authorization and should not be exposed to an untrusted network. Only users, products, and orders have REST controllers; other included data folders are not API endpoints. Pagination, filtering, and sorting are not implemented.

File mutation behavior is experimental: reads aggregate seed/batch files while writes use a resource-level file. A deleted record that remains in a seed file may reappear. Back up data and avoid using this release for valuable or production data.
